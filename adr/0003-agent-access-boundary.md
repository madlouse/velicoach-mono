# ADR-0003 智能体接入的敏感数据边界

状态：已接受（2026-11-13）

## 背景

主站要对人友好也对智能体友好：llms.txt、每页的 Markdown 版，以后有 MCP 工具，在 Claude、ChatGPT 这类平台上作为个人 Agent 的连接器。对外暴露的东西会被平台和第三方智能体读到。

## 决定

1. 公开内容（文章、里程碑、学习路径）对智能体完全开放：llms.txt、Markdown、站点地图。
2. 个人数据只经用户本人授权的工具访问，返回最少字段；健康明细和儿童数据不经任何对外工具返回。
3. 对外给的是工具和数据；主动提醒和长期记忆留在自己的 App 里。
4. 工具命名、入参和返回字段由 Veli 仓库维护，变更前通知主站频道。

## 后果

- MCP 公开放在 Veli B5，触发条件见 [roadmap.md](../roadmap.md)。
